# Home Assistant App: Web Kiosk

Shows any URL full-screen on the display attached to the Home Assistant OS
machine, using the Cage Wayland compositor and Chromium.

- Works with any web page: Home Assistant, a custom dashboard, anything.
- Has no website password options. Sign in once; the browser session persists.
- Touch input, output rotation, automatic restart after crashes.
- Optional public-key SFTP upload of a private static dashboard, served only
  to the browser inside the App container.

Primary target: Raspberry Pi 5 with the Raspberry Pi Touch Display 2.

See the **Documentation** tab for configuration and troubleshooting.
